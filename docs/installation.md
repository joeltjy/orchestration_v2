# Installation

## Stable release

To install orchestration_v2, run this command in your terminal:

```sh
uv add orchestration_v2
```

Or if you prefer to use `pip`:

```sh
pip install orchestration_v2
```

## From source

The source files for orchestration_v2 can be downloaded from the [Github repo](https://github.com/joeltjy/orchestration_v2).

You can either clone the public repository:

```sh
git clone https://github.com/joeltjy/orchestration_v2
```

Or download the [tarball](https://github.com/joeltjy/orchestration_v2/tarball/main):

```sh
curl -OJL https://github.com/joeltjy/orchestration_v2/tarball/main
```

Once you have a copy of the source, you can install it with:

```sh
cd orchestration_v2
uv sync
```
